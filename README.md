# Portfolio ReactJS

## Overview
This portfolio showcases my skills, interactive AI chatbot, and professional work. Built with **React, Tailwind CSS, and Node.js**, it is **continuously updated** to reflect progress on ongoing projects and new experiments. It demonstrates my expertise in **full-stack development**, **UI/UX design**, and **AI integrations**.

---

## AI Portfolio Chatbot
- Ask about my **skills, thesis, AI understanding, or contact info**.  
- Provides dynamic responses using **local JSON fallback data**.  
- Optional integration with **Hugging Face API** for advanced AI responses.  
- Includes **suggested question buttons** to guide interactions.

---

## Tech Stack

- Frontend: React, Tailwind CSS, JavaScript  
- Backend: Node.js (optional for API integrations)  
- Deployment: Vercel  
- AI: Hugging Face API

## How to Run
### 1. Clone the repository  
  
  ```bash
 git clone https://github.com/TurunenP/Portfolio.git
````

### 2.  Install dependencies:

```bash
cd portfolio
npm install
```

### 3. Start the development server

```bash
`npm start`
```

### 4. Open http://localhost:3000
 
```bash
in your browser
```

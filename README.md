# Portfolio Website

**Tech Stack:** React, JavaScript, Vercel (deployed)

## Overview
A personal portfolio website showcasing projects and experience with a clean, responsive design.

## Highlights
- **Responsive UI** built with React and modern design principles
- **Live Demo available** – visit [portfolio-turunenp.vercel.app](https://portfolio-turunenp.vercel.app/)
- **Easy navigation** and clear presentation of key projects

## Getting Started
1. Clone the repo: `git clone https://github.com/TurunenP/Portfolio.git`
2. Install dependencies: `npm install`
3. Run locally: `npm start`

## Why It Matters
This project serves as a central hub for showcasing my work and web development skills, with a focus on responsive design and modern JavaScript frameworks.
